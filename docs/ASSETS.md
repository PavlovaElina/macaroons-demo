# Ресурсы

Изображения и шрифты получены из учебного архива `m3(16part-lendig).zip`. В исходных материалах не было отдельных лицензионных документов. Репозиторий не заявляет исключительных прав на эти ресурсы и не предоставляет отдельного разрешения на их использование в других проектах.

## Изображения

Шесть PNG преобразованы в WebP с качеством 88. Их общий объём уменьшен с 901 036 до 137 158 байт.

| Файл                 | Назначение                          |
| -------------------- | ----------------------------------- |
| hero-macarons.webp   | Подарочная коробка на первом экране |
| macaron-closeup.webp | Иллюстрация блока о макарунах       |
| raspberry.webp       | Малина                              |
| mango.webp           | Манго                               |
| vanilla.webp         | Ваниль                              |
| pistachio.webp       | Фисташка                            |

На исходном изображении первого экрана сохранена надпись упаковки.

## Шрифты и значки

В проекте остаются Gilroy Regular, Gilroy Bold и Tavolga из исходных материалов. Основной текст использует системный шрифт, крупные заголовки — Georgia. Локальные шрифты загружаются с font-display: swap.

Favicon и значки интерфейса — SVG. Снимок в README показывает текущую версию сайта. `mockServiceWorker.js` распространяется в составе MSW; исходный комментарий библиотеки сохранён.
