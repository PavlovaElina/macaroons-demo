# Macaroons

Адаптивный сайт кондитерской на React и TypeScript: каталог, сборка подарочных коробок, корзина и оформление заказа. Портфолио-проект с демонстрационным API: настоящие заказы и платежи не выполняются.

[Открыть сайт](https://pavlovaelina.github.io/macaroons-demo/)

![Главная страница](docs/images/preview.png)

## Возможности

- Единый каталог с вкладками «Коробочки» и «Поштучно».
- Конструктор на 6 или 12 макарунов, готовые наборы «Все вкусы», упаковка и открытка.
- Счётчики товаров, редактирование коробок, объединение одинаковых вариантов, отмена удаления в течение 15 секунд.
- Восстановление корзины после перезагрузки с проверкой сохранённых данных.
- Самовывоз и доставка по Москве от коробки или шести макарунов, выбор даты и интервала.
- Маска российского телефона, ошибки полей, состояние отправки и подтверждение заказа.
- Загрузка, пустой каталог, ошибки API и повтор запроса.
- Клавиатурная навигация, доступные диалоги, поддержка reduced motion.

## Стек

React 19 · TypeScript · Vite · CSS · Mock Service Worker · Vitest · Playwright · axe · ESLint · Prettier.

## Запуск

Нужны Node.js **24+** и npm. Версия Node указана в `.nvmrc`.

```sh
npm ci
npm run dev
```

Сайт: [localhost:5174](http://localhost:5174). На macOS также можно запустить `scripts/start.command` двойным нажатием. Остановка сервера — Ctrl+C.

```sh
npm run check        # ESLint, unit-тесты, TypeScript и сборка
npm run test:e2e     # Браузерные сценарии desktop/mobile
npm run format:check # Проверка форматирования
npm run format      # Форматирование
npm run build       # Production-сборка в dist/
npm run preview     # Просмотр сборки на localhost:4174
```

Перед первым запуском браузерных тестов:

```sh
npx playwright install chromium
```

## Структура

```text
src/
  components/  каталог, конструктор, оформление, диалоги и уведомления
  data/        товары, упаковка, интервалы и условия получения
  mocks/       HTTP-обработчики демонстрационного API
  services/    HTTP-клиент и проверка ответов
  styles/      базовые стили, интерфейс каталога и состояния элементов
  utils/       расчёты, хранение корзины и валидация
  types.ts     модели предметной области
  App.tsx      композиция страницы и состояние покупки
public/        изображения, шрифты, favicon и Service Worker
scripts/       запуск на macOS
tests/e2e/     браузерные сценарии
docs/          архитектура, проверки и происхождение ресурсов
```

## Демонстрационные режимы

Сценарии включаются параметром URL: `?demo=slow`, `?demo=empty`, `?demo=catalog-error`, `?demo=order-error`. Параметр `?tools=1` открывает служебный переключатель режимов в подвале. Обычный запуск использует успешные ответы.

## Данные и ограничения

Цены хранятся в копейках и форматируются в рублях. В localStorage записывается только состав корзины. Контактные данные, адрес, комментарий и текст открытки не сохраняются после перезагрузки.

Каталог и оформление обслуживаются MSW в браузере. Для работы нужны localhost или HTTPS и Service Worker; открытие через `file://` не поддерживается. Готовая папка `dist/`, включая `mockServiceWorker.js`, подходит для статического HTTPS-хостинга. После успешных проверок ветка main автоматически публикуется на GitHub Pages. Pull request запускает проверки без публикации.

Каталог, адрес и условия получения вымышленные. Графика и шрифты происходят из учебных материалов; сведения об их происхождении и ограничениях — в [ASSETS.md](docs/ASSETS.md).
