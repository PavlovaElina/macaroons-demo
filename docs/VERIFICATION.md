# Проверки

Дата последней полной проверки: 9 ноября 2026.

## Автоматические проверки

- Чистая установка `npm ci` из lock-файла.
- ESLint, TypeScript с проверкой неиспользуемого кода и типизацией браузерных тестов, production-сборка Vite.
- 31 unit-тест: денежные расчёты, варианты корзины, лимиты, доставка, телефоны, готовые наборы, отмена удаления и восстановление повреждённых данных.
- Контракт заказа: неполный JSON, неверные типы, повторные ID, неполная коробка, некорректная дата/интервал и порог доставки отклоняются.
- 26 браузерных проверок: 13 сценариев на desktop Chromium и 13 в мобильной эмуляции. Проверяется production-сборка.
- axe: главная, обе вкладки каталога, корзина, оформление с ошибками и уведомление отмены удаления.
- `npm audit`: уязвимостей не обнаружено.
- GitHub Actions повторяет установку, форматирование, проверки, аудит и браузерные сценарии при push/pull request.

## Дополнительная проверка

После очистки и разделения CSS сравнивались вычисленные стили и размеры видимых элементов при ширинах 390, 768, 1440 px: различий не обнаружено. Ранее также проверялись 320, 375, 600, 1024 px без горизонтального переполнения.

Проверены: центрирование SVG в кнопках, одинаковая высота даты и времени, управление вкладками с клавиатуры, Escape и возврат фокуса. После 15 секунд возможность отмены удаления исчезает, корзина остаётся в удалённом состоянии.

## Ограничения

Safari, Firefox, физические телефоны, экранный диктор и масштаб 200–400% отдельно не проверялись. Эмуляция Chromium не заменяет реальное устройство. Полевые показатели Core Web Vitals не собирались.

Приложение использует демонстрационный API в браузере. Отсутствуют настоящий сервер заказов, остатки, проверка зоны доставки и обработка платежей. Собранный сайт дополнительно проверен в подпапке `/macaroons-demo/`: каталог, ресурсы, корзина и успешное оформление работают без ошибок запросов. Публичный хостинг не включён в workflow. Происхождение ресурсов описано в ASSETS.md.
